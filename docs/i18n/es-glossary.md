# LYNX Spanish (es) glossary

Neutral / international Spanish, meant to read naturally in Spain and Latin America.

## Register and style
- Informal "tú" (as most current Spanish music/creative software and OS UIs do). Never "vosotros", never "usted".
  Imperatives in help text: "Arrastra", "Haz clic", "Elige". Commands/buttons/menu items: infinitive
  ("Guardar proyecto", "Abrir carpeta").
- Avoid region-specific words: "archivo" (not "fichero"), "PC"/"equipo" (not "ordenador"/"computadora"),
  "control" for a knob (not "perilla"/"potenciómetro"), "clic" (not "click").
- Sentence case (Spanish does not use Title Case): "Configuración de audio", not "Configuración De Audio".
- Opening marks ¿ ¡ are required. Quotes: “ ” (avoids escaping). Ellipsis: keep "..." as the source has it.
- Units keep the English spacing of the source ("10 ms", "-6 dB", "120 BPM"). Decimal format is not changed
  (numbers come from code).
- Shortcuts: keep key names (Ctrl, Shift, Alt, F5, Esc, Tab, Delete/Del → "Supr" and Backspace → "Retroceso" (Spanish keyboard labels) in plain text; bracketed key tags such as [Backspace] [Space] [Up] stay as they are).
  "Space" (key) → "Espacio" (Spanish keyboards label it so). "Alt+drag" → "Alt+arrastrar".
  [LMB] [RMB] [2xLMB] [Alt] tags stay as they are.

## Kept in English
Channel Rack, Piano Roll, Playlist, Mixer, Browser (LYNX/FL proper names, as Spanish FL users say them);
plugin, preset, sample, loop (the audio file), slot, swing, stem, insert (Mixer insert), LFO, MIDI, CC, NRPN, MPE,
BPM, VST3, CLAP, ASIO, WASAPI, ALSA, JACK, SoundFont, FL Studio, all plugin/engine names (Sytrus, Harmor, Fruity…,
LYNX Tune, Facet EQ, VFX…), Wet/Dry knob labels, Ratio, Gate, Drive, Pitch bend, glide/portamento, file extensions,
units (Hz, kHz, dB, ms, %, st, ct), note names (C4, F#).
