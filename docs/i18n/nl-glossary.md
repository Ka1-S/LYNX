# LYNX Dutch (nl) glossary

Reference for `resources/i18n/nl.txt` (language header "Nederlands"). English is the source language;
the pt-BR table was only used as a hint for meaning. Written for both the Netherlands and Flanders:
neutral standard Dutch, no regionalisms.

## Register and style

- **Form of address: informal "je/jouw", but avoid direct address wherever possible.** Dutch creative and
  music software, Apple, Google and most Dutch producer communities use "je"; "u" feels like banking or
  government software. Commands use the infinitive ("Project opslaan", "Kanaal hernoemen"), descriptions use
  the third person ("Speelt het huidige pattern in een loop af"). "Je" only where a sentence really talks
  to the user.
- **Keep the producer jargon English.** Dutch producers say pattern, clip, track, sample, preset, plugin,
  loop, step, swing, send, insert, slot, mute, solo, quantize (as a noun/label "Quantize"; verb
  "kwantiseren" is used in sentences), velocity, pan, automation clip, arpeggiator, sidechain, gate, LFO,
  cutoff, resonance, attack/decay/sustain/release, wet/dry, gain, buffer, latency. These are written
  lower case inside sentences (Dutch rules), compounds are hyphenated or joined as Dutch does
  ("pattern-modus", "mixertrack", "pluginvenster", "audioclip", "automation clip").
- **Capitalisation:** Dutch sentence case — only the first word (and proper names) capitalised, never
  English Title Case. ALL-CAPS knob labels (FREQ, GAIN) stay in caps.
- **Quotes:** straight double quotes as in the English source, escaped as \" (Dutch UI commonly uses "…"
  or ‘…’; we keep the source's quotes so escapes stay identical).
- **Ellipsis:** keep "..." exactly as in English.
- **Numbers and units:** keep the source spacing ("{0}%", "10 ms"). Decimals written literally in a
  sentence use a comma (0,5); placeholders are formatted by the code and left alone.
- **Shortcuts:** Dutch keyboards are US-International layout and print Ctrl, Shift, Alt, Enter, Esc,
  Backspace, Tab, Delete — all stay in English. Space → **spatie** (key cap `[Spatie]`), arrows →
  **pijltjestoetsen**, `[Up]`/`[Down]`/`[Left]`/`[Right]` → `[Omhoog]`/`[Omlaag]`/`[Links]`/`[Rechts]`.
  "Ctrl+drag" → "Ctrl+slepen", "Alt-click" → "Alt+klik", "right-click" → "rechtsklik" (noun) /
  "rechtsklikken" (verb), "double-click" → "dubbelklik".
- **Hint-bar tokens** `[LMB]`, `[RMB]`, `[2xLMB]`, `[MMB]`, `[Wheel]` stay exactly in English. Non-markup
  brackets like "[double-click]" are translated as text ("[dubbelklik]").
- **Lists separated by "|"** keep the same number of items; functional modes are translated, algorithm/
  preset names stay English.

## Stays in English (unchanged)

Channel Rack, Piano Roll, Playlist, Mixer, Browser (LYNX/FL proper names; Dutch FL users use them in
English; "de Channel Rack", "de Piano Roll", "de Playlist", "de Mixer", "de Browser"). Plugin, engine and
product names (Sytrus, Harmor, Fruity …, LYNX Tune, Facet EQ, VFX, FL Studio, VST/VST3/CLAP, ASIO, WASAPI,
ALSA, JACK), file extensions, units (Hz, kHz, dB, ms, %, BPM, st, ct), note names (C4, F#), MIDI terms
(MIDI, CC, NRPN, MPE).
