# LYNX Indonesian (id) glossary

Reference for `resources/i18n/id.txt` (language header "Bahasa Indonesia"). English is the source language;
the pt-BR table was only used as a hint for meaning. Standard Indonesian (Bahasa Indonesia baku) as used by
Windows/Android/macOS in Indonesian, mixed with the English jargon Indonesian producers actually use (FL Studio
is very popular in Indonesia and its community talks about pattern, sample, plugin, preset, mixer, track...).

## Register and style

- **Form of address: "Anda"** (capitalised), the convention of Windows, Android, Google and Adobe in
  Indonesian. Avoid direct address where possible: commands use the imperative/base verb ("Simpan proyek",
  "Ganti nama channel"), descriptions use a neutral sentence ("Memutar pattern saat ini dalam loop").
- **Capitalisation:** Indonesian sentence case — only the first word and proper names are capitalised, never
  English Title Case. ALL-CAPS knob labels (FREQ, GAIN) stay in caps.
- **English jargon** inside a sentence is written lower case and is not italicised; Indonesian affixes are not
  glued onto English words (write "di-mute" only if unavoidable; prefer "bisukan", "dikuantisasi" etc.).
  Plural is not marked ("3 pattern", "semua clip"); reduplication ("pattern-pattern") is avoided.
- **Quotes:** straight double quotes as in the English source, escaped as \".
- **Ellipsis:** keep "..." exactly as in English.
- **Numbers and units:** keep the source spacing ("{0}%", "10 ms"). Decimals written literally in a sentence
  use a comma (0,5); placeholders are formatted by the code and left alone.
- **Shortcuts / keys:** Indonesian keyboards are US layout; Ctrl, Shift, Alt, Enter, Esc, Backspace, Tab,
  Delete, Space and the key caps in brackets ([Ctrl], [Space], [Up]...) stay ASCII/English. "Arrows" →
  "Tombol panah". "Ctrl+drag" → "Ctrl+seret", "Alt-click" → "Alt+klik", "right-click" → "klik kanan",
  "double-click" → "klik ganda", "mouse wheel" → "roda mouse", "Wheel:" → "Roda:".
- **Hint-bar tokens** `[LMB]`, `[RMB]`, `[2xLMB]`, `[MMB]`, `[Wheel]` stay exactly in English.
- **Lists separated by "|"** keep the same number of items; functional modes are translated, algorithm/preset
  names stay English.

## Stays in English (unchanged)

Channel Rack, Piano Roll, Playlist, Mixer, Browser (LYNX/FL proper names; Indonesian FL users use them in
English). Plugin, engine and product names (Sytrus, Harmor, Fruity …, LYNX Tune, Facet EQ, VFX, FL Studio,
VST/VST3/CLAP, ASIO, WASAPI, ALSA, JACK), file extensions, units (Hz, kHz, dB, ms, %, BPM, st, ct), note names
(C4, F#), MIDI terms (MIDI, CC, NRPN, MPE), envelope stage names (Attack, Hold, Decay, Sustain, Release),
waveform names (Sine, Saw, Square, Triangle, Pulse, Noise), EQ filter types (Peak, Low shelf, High shelf, Low cut,
High cut, Band-pass, Notch), drum names (Kick, Snare, Hat, Clap).
