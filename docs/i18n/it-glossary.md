# LYNX Italian (it) glossary

Standard Italian, as used by Italian producers and in Italian-localized DAWs/OS UIs.

## Register and style
- Informal "tu" (as Apple/Google Italian UIs and creative/music software do). Never "Lei"/"voi".
  Help text imperatives: "Trascina", "Fai clic", "Scegli". Commands/buttons/menu items: imperative 2nd person
  singular, the Italian UI convention ("Salva progetto", "Apri cartella", "Annulla").
- Sentence case (Italian does not use Title Case): "Impostazioni audio", not "Impostazioni Audio".
- Quotes: « » or “ ” (avoids escaping); prefer “ ”. Ellipsis: keep "..." as the source has it.
- Units keep the English spacing of the source ("10 ms", "-6 dB", "120 BPM"). Numbers come from code (no change).
- Elision/apostrophes: use the typographic rules of Italian ("l'audio", "dell'insert") with the ASCII apostrophe '.
- Shortcuts: keep key names (Ctrl, Shift, Alt, F5, Esc, Tab, Enter). Plain-text Delete key → "Canc",
  Backspace stays "Backspace", Space (key) → "Spazio" (Italian keyboards label it so). Bracketed key tags such as
  [Backspace] [Space] [Up] stay as they are. "Alt+drag" → "Alt+trascina".
  [LMB] [RMB] [2xLMB] [MMB] [Wheel] tags stay exactly as they are.

## Kept in English
Channel Rack, Piano Roll, Playlist, Mixer, Browser (LYNX/FL proper names, as Italian FL users say them);
pattern, clip, plugin, preset, sample, loop (audio file), slot, step, swing, stem, insert, send (labels), velocity,
pan (label), mute/solo (labels), LFO, MIDI, CC, NRPN, MPE, BPM, VST3, CLAP, ASIO, WASAPI, ALSA, JACK, SoundFont,
FL Studio, all plugin/engine names (Sytrus, Harmor, Fruity…, LYNX Tune, Facet EQ, VFX…), Wet/Dry knob labels,
Attack/Decay/Sustain/Release/Hold knob labels (ADSR), Ratio, Gate, Drive, Pitch bend, glide, delay/reverb
(effects), cutoff (label), fader, buffer, file extensions, units (Hz, kHz, dB, ms, %, st, ct), note names (C4, F#).
