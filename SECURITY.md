# Security policy

## Supported versions
Only the latest LYNX SHARE alpha release gets fixes. Please check the problem still happens there before reporting it.

## Reporting a vulnerability
Please **don't open a public issue** for security problems (for example a crafted project, sample or preset file that makes LYNX SHARE run code, or a problem with the crash-report upload or the website).

Report it privately instead: on GitHub go to **Security › Report a vulnerability** ([direct link](https://github.com/Ka1-S/LYNX-SHARE/security/advisories/new)). Include the LYNX SHARE version, OS, and steps or a file to reproduce it.

You'll get an answer as soon as possible. After a fix is released, the report can be made public, with credit to you if you want.
