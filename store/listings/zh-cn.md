## Description

LYNX（在此以 LYNX SHARE 之名发布）是一款免费开源的数字音频工作站（DAW），用来做 Beat、写歌。它沿用了 Beatmaker 们钟爱的基于 Pattern 的工作流程——步进音序器式的 Channel Rack、Pattern、Piano Roll、支持编排的 Playlist，以及带插入、发送和侧链的 Mixer——并且力求在任何电脑上都轻快流畅。

• 轻量：无锁音频引擎将通道和混音轨分配到所有 CPU 核心，自动跳过空闲通道，长音频直接从硬盘流式读取。
• 齐全：100 多款内置乐器和效果器——合成器、鼓机、采样器、均衡器、压缩器、限幅器、混响、延迟、音高校正、可视化工具等等。
• 你的插件：支持 VST3、CLAP 和 VST2 乐器与效果器，每个插件都可选择在独立的沙箱进程中运行，插件崩溃也不会拖垮整个工程。
• 可打开 FL Studio 工程（.flp），保留其中的 Pattern、音符、混音台、自动化和采样，并可导入 MIDI 文件。
• 低延迟：支持 ASIO（包括适用于任何设备的 LYNX 自带 ASIO 驱动）以及 WASAPI 共享和独占模式。
• 录制音频和 MIDI、编辑音频、自动化任意参数，导出为 WAV、FLAC、MP3、OGG 或分轨（stems）。
• 界面语言：简体中文、繁体中文、英语、葡萄牙语、西班牙语、法语、德语、日语、韩语等 15 种语言。

无需账号，没有订阅，没有广告，也没有遥测。LYNX 是自由软件（GNU AGPL-3.0），源代码托管在 GitHub 上。

LYNX 是一个独立项目，与 Image-Line 无关联，也未获得其认可。FL Studio 是 Image-Line Software 的商标。其他产品名称均为其各自所有者的商标。

LYNX 目前处于 Alpha 阶段：难免有不完善之处，如遇问题请在 GitHub 上反馈。

## Features

1. 基于 Pattern 的工作流程：步进音序器 Channel Rack、Piano Roll、支持编排的 Playlist 和完整的 Mixer
2. 可打开 FL Studio 工程（.flp）和 MIDI 文件
3. 100 多款内置乐器和效果器
4. 支持 VST3、CLAP 和 VST2 插件，可选在独立进程中沙箱运行
5. 低延迟音频：ASIO、WASAPI 共享和独占模式
6. 多核引擎，老电脑也能轻松运行
7. 音频和 MIDI 录音、音频编辑器、自动化片段
8. 导出 WAV、FLAC、MP3、OGG 和分轨
9. 支持简体中文等 15 种界面语言
10. 免费开源（AGPL-3.0）：无需账号，无广告，无遥测
