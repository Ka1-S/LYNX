## Description

LYNX（ここではLYNX SHAREとして公開）は、ビートや楽曲を制作するための無料・オープンソースのDAW（デジタル・オーディオ・ワークステーション）です。ステップシーケンサー型のChannel Rack、パターン、Piano Roll、アレンジメント対応のPlaylist、インサート・センド・サイドチェインを備えたMixerという、ビートメイカーに愛されるパターンベースのワークフローを採用し、どんなPCでも軽快に動作するよう設計されています。

※ LYNXのインターフェースは現在、英語とポルトガル語（ブラジル）のみに対応しています（日本語表示には未対応です）。

• 軽快：ロックフリーのオーディオエンジンがチャンネルとミキサートラックをCPUの各コアに分散。鳴っていないチャンネルは処理をスキップし、長いオーディオはディスクからストリーミング再生します。
• 充実：シンセ、ドラムマシン、サンプラー、EQ、コンプレッサー、リミッター、リバーブ、ディレイ、ピッチ補正、ビジュアライザーなど、100種類以上の内蔵インストゥルメントとエフェクト。
• お気に入りのプラグインも：VST3、CLAP、VST2のインストゥルメントとエフェクトをホスト。各プラグインを個別のサンドボックスプロセスで動かすこともでき、プラグインがクラッシュしてもセッションは落ちません。
• FL Studioのプロジェクト（.flp）をパターン、ノート、ミキサー、オートメーション、サンプルごと読み込めるほか、MIDIファイルのインポートにも対応。
• 低レイテンシー：ASIO（どのデバイスでも使えるLYNX独自のASIOドライバーを含む）、WASAPIの共有モードと排他モードに対応。
• オーディオとMIDIのレコーディング、オーディオ編集、あらゆるパラメーターのオートメーション、WAV・FLAC・MP3・OGG・ステムへの書き出し。
• インターフェース：英語とポルトガル語（ブラジル）（他の言語にも対応予定）。

アカウント登録、サブスクリプション、広告、テレメトリーは一切ありません。LYNXはフリーソフトウェア（GNU AGPL-3.0）で、ソースコードはGitHubで公開しています。

LYNXは独立したプロジェクトであり、Image-Lineとは提携しておらず、同社による承認も受けていません。FL StudioはImage-Line Softwareの商標です。その他の製品名は、それぞれの所有者の商標です。

LYNXはアルファ版です。粗削りな部分もありますので、問題を見つけたらGitHubでご報告ください。

## Features

1. パターンベースのワークフロー：ステップシーケンサー型のChannel Rack、Piano Roll、アレンジメント対応のPlaylist、本格的なMixer
2. FL Studioのプロジェクト（.flp）とMIDIファイルを開けます
3. 100種類以上の内蔵インストゥルメントとエフェクト
4. VST3、CLAP、VST2プラグインをホスト。個別プロセスでのサンドボックス実行も可能
5. 低レイテンシーのオーディオ：ASIO、WASAPI共有モード・排他モード
6. 古いPCでも軽快に動くマルチコア対応エンジン
7. オーディオとMIDIのレコーディング、オーディオエディター、オートメーションクリップ
8. WAV、FLAC、MP3、OGG、ステムへの書き出し
9. インターフェース：英語とポルトガル語（ブラジル）（他の言語にも対応予定）
10. 無料のオープンソース（AGPL-3.0）：アカウント不要、広告なし、テレメトリーなし
